# 凌空 · 2D 羽毛球

## 启动

```powershell
pip install -r requirements.txt
python server.py
```

服务启动后，本机访问 `http://localhost:8082`。同一局域网的其他设备访问
`http://服务器局域网IP:8082` 即可加入真人匹配。

可通过环境变量修改端口：

```powershell
$env:HTTP_PORT=8082
$env:WS_PORT=8766
python server.py
```

防火墙需允许网页端口和 WebSocket 端口的 TCP 入站连接。若网页经过反向代理或使用了
不同的 WebSocket 地址，可以在网址后添加 `?ws=ws://服务器IP:端口`。

## 操作

- `A / D`：前进、后退
- `W` 或空格：跳跃
- `H`：平抽；发球时为平快发球
- `J`：高远球；发球时为高远发球
- `K`：站立时吊球、跳起时杀球；发球时为网前短发球
- `R`：使用已装备的一次性比赛技能

发球不会自动进行，发球方准备完成后必须按 `H / J / K` 选择发球方式。装备中心同时
出售高级球拍与一次性比赛技能；技能每场只能使用一次，该场比赛结束后自动消耗。

球币获取方式：机器人对战获胜 `+180`，真人对战获胜 `+450`，完成真人对战但落败
仍可获得 `+120`。

采用国际羽联常用的每球得分制：每局 21 分、20 平后领先 2 分胜、29 平后先到 30 分胜，
三局两胜；每局结束交换场地，决胜局一方先到 11 分时再次交换场地。

真人比赛的移动、击球有效距离、球路、计分、球币和胜场都由服务器判定并持久化到
`players.json`。客户端只上传按键输入，断线后保留 20 秒重连时间。
