# 裂隙行动：战术前线

浏览器端第一人称 3D 战术枪战。四张全封闭室内战场、团队 AI、1V1/1V2/2V2/5V5、30 把各具独立外形的枪械、命中分区、姿态和四类投掷物。所有枪械开局全部解锁，可直接在军械库或靶场工作台配置使用。

## 启动

从仓库根目录启动静态页面：

```powershell
python -m http.server 3456
```

访问 `http://127.0.0.1:3456/shooting/`。单机团队战无需后端。

启动后需使用预置账户登录，当前账户为 `gyagp`、`lucas` 或 `janet`。登录状态会保留，刷新页面无需再次输入密码；主动退出后才会清除登录状态。登录后可在“账户管理”中查看该账户的比赛记录或切换账户。游戏不保存未结束的对局，也不提供手动存档或继续游戏；装备、配件、声音设置和已完成比赛战绩按账户独立保存。

局域网联机需另开终端：

```powershell
pip install -r shooting/requirements.txt
python shooting/server.py
```

联机服务监听 `8766` 端口。每个账户拥有固定的六位房间号，刷新页面或重启服务后重新创建仍保持不变；房主把房间码发给战友即可。三人可选择“1V2 三人自由分组”，红蓝双方可随时在 `1:2` 与 `2:1` 之间切换；其他模式最多 5V5。

## 控制

- `W/A/S/D` 移动，鼠标控制视角，左键射击或拔栓投掷，`Q` 切换开镜
- `F` 跳跃，`G` 蹲伏，`H` 卧倒，`Shift` 冲刺，`E` 或鼠标右键换弹
- 0.6 米以内的台阶可直接走上；货箱、矮墙与高架平台需要起跳（跳跃高度约 1.35 米），逐级即可登顶检修走道
- `1/2` 两把枪，`3` 手雷，`4` 燃烧瓶，`5` 烟雾弹，`6` 闪光弹
- 靶场内靠近工作台按 `E`，可单独微调正前方靶标并自由选择枪械
- 再次按当前装备数字会收起装备并略微提高移动速度

栓动狙击枪射击后会自动完成拉栓动作；拉栓期间射击输入被锁定，动作结束后才能发射下一枪。

手雷从拔栓开始 7 秒爆炸；烟雾弹和闪光弹在 5 秒时生效。不同模式的携带上限显示在大厅模式卡片和新手教程中。

1V1、2V2、5V5 均为 5 分钟持续复活制，死亡 5 秒后重新投入战斗，时间结束时击败数更多的小队获胜。地图只会在玩家点击进入战场后随机生成，并播放战区扫描动画。掩体为高低不一的墙体：约 1 米可翻越、1.4 米齐胸、2 米全身、2.7 米以上为高隔断。每张地图还有可攀爬的立体地形——三级货箱阶梯（0.6/1.2/1.8 米）、2.4 米高架平台和 3.2 米检修走道，逐级起跳即可登顶。小地图按高度着色，可攀爬地形显示为青色。切换到其他程序导致鼠标控制断开时，可通过恢复面板重新连接操作。

受到 AI 或联机玩家攻击时，准星周围会显示来袭方向，并提示攻击者和本次伤害；连续受击会逐次刷新。燃烧区域等没有明确攻击方向的伤害仅显示文字提醒，避免给出错误方向。

游戏不设金币、购买或对局奖金；全部枪械开局即可直接装备。

红点瞄准镜采用低矮微型管式结构，带透明镜片、中央发光红点和调节旋钮；开镜时使用无遮挡的专用红点视图。

靶场使用唯一固定的 60 米纵深封闭室内靶馆并直接进入，包含 5 条带隔断的靶道。所有靶标默认位于最近的 10 米且关闭无敌；每条靶道前的工作台可单独微调距离（10—45 米）、无敌状态、当前枪械与配件，45 米靶位与末端吸弹墙之间保留安全距离。命中标靶时会在标靶上方显示纯数字伤害飘字并上浮渐隐，高伤害使用红色强调但不显示“爆头”等文字。

联机比分由服务端确认每次阵亡并实时广播，回合结束时再次下发最终权威比分；客户端会等待最终比分后再显示结算。连接没有权威比分的旧服务时，各客户端也会通过玩家累计阵亡数和随状态携带的本地比分持续互相校正，避免其他玩家界面停在 0:0。若检测到旧版联机服务，页面仍会提示重启；历史中“已有击败或阵亡却显示 0:0”的错误记录会被自动清理，也不会再次写入。三人使用同一地图随机种子与碰撞布局，枪械配件、枪火、弹道、命中火花、投掷物、爆炸、死亡、复活和比分都会同步到房间内所有玩家。远端角色模型会按对方真实视角方向旋转，不再反向背对。

军械库和靶场工作台均提供瞄具、枪口、握把、弹匣、枪托槽位。点击空槽即可从兼容配件中选择；后坐、精度、弹匣容量、换弹速度和消音效果会应用到实战数值。每次选择或卸下配件都会立即自动保存；切换 1、2 号武器栏时会自动打开该栏实际装备的枪，两栏配置完全独立且按登录账户隔离。

大厅的“声音设置”和局内暂停菜单均可开关脚步声、调整脚步声音量，设置随当前账户保存。玩家自己、AI 与联机角色移动时都会发出与走路、冲刺、蹲伏或趴下相匹配的脚步声；其他角色在 30 米听觉范围内会随接近逐渐增大音量，并通过左右声道提示方向。

AI 会优先选择视线清晰或生命值较低的目标，预测移动方向、快速侧移绕开障碍，并在中远距离保持压制；反应、射速、命中率和伤害均已强化。AI 开火前仍会检查枪口到目标之间的墙体和掩体，不会靠穿墙攻击提高难度。人物若因高低平台进入碰撞体，系统会自动移回最近的安全位置。

## 视觉资源

- 大厅、单机 AI、靶标及所有联机玩家统一使用游戏最初的程序化 3D 干员形象，不再加载或替换为外部人物模型，因此每台电脑看到的人物轮廓完全一致。
- 枪械与投掷物模型全部由 `visuals.js` 按 `weapon-specs.js` 中的真实外形规格程序化拼装，30 把枪各有独立轮廓（无托、弹鼓、螺旋弹筒、弹链盒、木制枪身、两脚架等），配件也会实时体现在模型上。
- 室内战场与靶场由 `arena.js` 构筑：吊顶灯具、桁架、通风管道、承重柱、高低不一的掩体墙与可攀爬的立体地形。
- 原始干员由 `visuals.js` 程序化构建（1.82 米真实身高，含头盔夜视支架、护目镜、防弹背心、弹匣袋、护膝与作战靴），命中分区取头盔与背心体积。

## 重新生成外形规格

`weapon-specs.js` 与 `tools/art-specs.json` 由 Gemini 依据真实枪械 / 装备外形生成。需要重新拉取时（需设置 `GOOGLE_API_KEY`）：

```powershell
node shooting/tools/fetch-weapon-specs.mjs
node shooting/tools/fetch-art-specs.mjs
```
